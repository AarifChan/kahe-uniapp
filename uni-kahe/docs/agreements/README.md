## 整理口径

- 品牌名称统一为“卡核”，商品暂存位置统一称为“寄存柜”。
- 已拆分标题、条款和列表，并修正明显错别字、重复编号及标点问题。
- 未新增具体运费金额、概率、售后时限等业务规则；各玩法特有规则仍以对应页面公示为准。

## 发布前待确认事项

以下口径在项目原文中并不一致，本次未擅自替业务方作出选择。正式发布前应由产品、运营及法务确认，并同步修改相关文档：

1. **未成年人购买规则**：部分原文为“18 周岁以下禁止购买”，部分原文为“未满 8 周岁禁止购买，8 周岁及以上未成年人经监护人同意后可购买”。
2. **运费及包邮门槛**：原文同时存在“12 元/单、无包邮门槛”和“满 5 件包邮、不足 5 件收 10 元”两种说法。
3. **承运方**：原文同时出现顺丰速运和中通物流。
4. **发货时效**：大部分原文为申请后 1～7 个工作日、节假日顺延 1～5 天；公告中另有 3～7 个工作日、节假日顺延 1～7 天的表述。
5. **运营与联系信息**：隐私政策中的客服电话、客服微信及运营主体联系地址仍需补齐真实信息。
6. **第三方 SDK 目录**：隐私政策提及第三方 SDK 目录，但项目中未发现对应清单，接入前应补充。

> 本目录是项目现有文案的整理稿，不替代法律审查。涉及用户权益、未成年人、个人信息及退换货的条款，上线前建议由法务复核。
