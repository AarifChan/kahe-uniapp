# 卡核隐私政策

卡核（以下简称“我们”）深知个人信息对您的重要性，会尽力保护您的个人信息安全。我们致力于维持您对我们的信任，恪守权责一致、目的明确、选择同意、最小必要、确保安全、主体参与、公开透明等原则。同时，我们承诺按照业界成熟的安全标准，采取相应的安全保护措施保护您的个人信息。

请在使用我们的产品或服务前，仔细阅读并了解本《卡核隐私政策》，以便更好地了解我们如何收集、使用、存储和共享您的个人信息。

## 一、我们收集的信息

我们根据合法、正当、必要的原则，仅收集实现产品功能所必要的信息。

### 1.1 您在使用我们服务时主动提供的信息

- 您在注册账户时填写的信息，如昵称、头像、手机号码等；
- 您在使用服务时上传或填写的信息，如收货地址、联系人信息等；
- 您通过我们的客服或参加我们举办的活动时提交的信息。

### 1.2 我们在您使用服务时获取的信息

- **日志信息**：当您使用我们的服务时，我们可能会自动收集相关信息并存储为服务日志；
- **设备信息**：设备型号、操作系统版本、唯一设备标识符等；
- **软件信息**：软件版本号、浏览器类型等；
- **网络信息**：IP 地址等；
- **服务使用信息**：您在使用我们服务时搜索、查看的信息等；
- **位置信息**：您开启设备定位功能并使用基于位置提供的相关服务时，我们收集的有关您位置的信息。

## 二、我们如何使用信息

我们严格遵守法律法规的规定以及与用户的约定，将收集的信息用于以下用途：

- 向您提供我们的各项服务；
- 满足您的个性化需求；
- 产品开发和服务优化；
- 安全保障；
- 向您推荐您可能感兴趣的广告、资讯等；
- 评估、改善我们的广告投放和其他促销及推广活动的效果。

## 三、信息共享

目前，我们不会主动共享或转让您的个人信息至第三方。如存在其他共享或转让您个人信息的情形，我们会征得您的明示同意。

我们会对合作方获取信息的软件工具开发包（SDK）进行严格的安全监测，以保护数据安全。我们接入的相关第三方 SDK 将在 SDK 目录中列明。

请注意，第三方 SDK 可能因版本升级、策略调整等原因导致数据处理类型发生变化，请以第三方公示的官方说明为准。

## 四、信息存储与保护

### 4.1 信息存储地点

我们会按照法律法规规定，将境内收集的用户个人信息存储于中国境内。

### 4.2 信息存储期限

一般而言，我们仅在为实现处理目的所必需的时间内保留您的个人信息。例如：

- **手机号码**：若您需要使用卡核服务，我们需要持续保存您的手机号码，以保证您正常使用该服务；
- **账户注销**：当您注销账户后，我们将删除您的个人信息或进行匿名化处理，法律法规另有规定的除外。

### 4.3 信息安全

- 我们努力为用户的信息安全提供保障，以防止信息丢失、不当使用、未经授权访问或披露；
- 我们将在合理的安全水平内使用各种安全保护措施，保障信息安全；
- 我们建立专门的管理制度、流程和组织，保障信息安全；
- 若发生个人信息泄露等安全事件，我们会启动应急预案，阻止安全事件扩大，并以推送通知、公告等形式告知您。

## 五、您的权利

在您使用卡核服务期间，为了让您更便捷地查询、访问、删除、更正您的个人信息，我们在产品设计中提供了相应的操作设置，您可参考以下指引：

- **查询或访问个人信息**：您可以在“我的”页面查看基本信息；
- **更正个人信息**：您可以在“我的－设置”中修改个人信息；
- **删除个人信息**：您可以联系客服申请删除个人信息；
- **注销账户**：您可以在“设置”中申请注销账户。

## 六、未成年人保护

我们非常重视对未成年人个人信息的保护。根据相关法律法规的规定，若您是 18 周岁以下的未成年人，在使用卡核服务前，应事先取得家长或法定监护人的书面同意。

若您是未成年人的监护人，当您对所监护未成年人的个人信息有相关疑问时，请通过本政策公示的联系方式与我们联系。

## 七、隐私政策的变更

我们可能会适时修订本隐私政策。当隐私政策条款发生变更时，我们会在您登录及版本更新时，以推送通知、弹窗等形式向您展示变更后的政策。

请您注意，只有在您点击弹窗中的同意按钮后，我们才会按照变更后的隐私政策收集、使用、存储您的个人信息。

## 八、联系我们

如果您对本隐私政策有任何疑问、意见或建议，或者您希望行使个人信息相关权利，请通过以下方式与我们联系：

- **客服微信**：请在“我的”页面联系客服；
- **客服电话**：请在小程序内查看；
- **运营主体**：佛山市顺德区卡核贸易商行。
