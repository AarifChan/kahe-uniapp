# 发货须知

1. **发货门槛与邮费**：一件即可申请发货，无发货数量门槛，需支付 12 元邮费。
2. **收货信息**：请务必确保默认收货地址真实有效。因地址错误或其他个人原因导致的损失，由您自行承担。
3. **发货时效**：平台会根据申请发货的先后顺序，在 1～7 个工作日内安排发货；如遇节假日或特殊情况，可能暂停发货或顺延 1～5 天。平台会尽力将现货商品尽快送达。
4. **开箱凭证**：收货前建议录制开箱视频。如遇商品运输损坏或其他问题，请提供开箱视频并联系在线客服处理。
5. **品相确认**：不同用户对卡牌品相、评级评分可能有不同需求。申请发货前请确认卡牌品相，购买界面会展示卡牌品相及《卡牌品相定义》。
6. **发货范围**：目前仅支持发货至中国大陆区域，香港、澳门、台湾地区及海外地区暂不支持。
