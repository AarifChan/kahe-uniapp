# 无限赏规则与说明

## 一、玩法说明

1. 随机精美卡片为开赏类盲盒商品，一经购买不接受无理由退款，请谨慎、理性购买，未成年人禁止下单。
2. 您可根据需求点击购买 N 张，获得 N 张精美卡片，同时获得对应张数的赠送赏品。100% 有赠品，赏品类型及获得概率以商品详情为准。
3. 所有赏品概率及获得记录均在赏品详情页展示，请参考后下单。平台遵循公平、公正、公开原则。
4. 赏品按稀有度分为 SAR 赏、UR 赏、SSR 赏、SR 赏、R 赏等等级，每个品级的获得概率以页面公示为准。

## 二、特殊模式说明

### 2.1 保底模式与幸运值

如开启幸运池，每当幸运值满后，必出一个限定等级的商品。具体等级以商品详情为准，所需幸运值数量以幸运值展示界面为准。

幸运值为单套累计；多套一起购买时不会合并叠加，而是分开计算。

### 2.2 魔王奖励

如开启魔王奖励，获得带有魔王凭证赏品的用户将成为当前魔王。之后产生的购买金额，将按照商品详情页“魔王奖励”公示的比例奖励给当前魔王，直至下一位获得带有魔王凭证赏品的用户成为新魔王。

## 三、发货规则

1. 开赏后的赏品会放入寄存柜，您可到“寄存柜”内手动申请发货。
2. 请务必确保默认收货地址真实有效。因地址错误或其他个人原因导致的损失，由您自行承担。
3. 平台会根据申请发货的先后顺序安排发货，并在申请后 1～7 个工作日内发出；如遇节假日或特殊情况，可能暂停或延迟发货。
4. 平台默认使用中通物流，一件起发，12 元邮费由您支付。
5. 如因非人为原因导致赏品损坏，请及时联系客服，并按照封箱贴提示录制开箱视频。经核实后可调换新的同款赏品，具体以《售后与退换货规则》为准；不支持退货或调换其他款赏品。
6. 其他发货事项以《发货规则》《发货须知》及订单页面公示为准。

## 四、公平交易与恶意行为处理

为保障每位用户公平享有冲赏的权利，平台会对冲赏行为进行实时监测。对于出现恶意行为的用户，平台有权要求其退还因恶意行为获得的额外利益并进行警告；出现两次恶意行为的，用户将被列入黑名单并被冻结卡核一番赏账户，无法使用一番赏购买服务及其他相关服务。

恶意行为包括但不限于：

- 开箱后无质量问题而以各种理由要求退款；
- 欺骗或与他人联合欺骗其他冲赏用户；
- 利用系统漏洞恶意冲赏；
- 其他破坏公平交易秩序的行为。

## 五、商品缺货处理

由于市场变化、系统问题、不可抗力等因素影响，您提交订单中的商品可能出现缺货。在此情形下，卡核一番赏将以有效方式（包括但不限于向您提供的联系电话发送手机短信）通知您并提供解决方案，包括但不限于取消订单、换货、调货等。

请您在未收到商品前留意通知。若卡核一番赏自发出通知起一周内超过两次无法与您取得电话联系，且您在收到通知超过 30 天后仍未主动联系在线客服，平台有权取消订单并退还您支付的冲赏费用。缺货商品是否补货不再另行通知，如您对该商品感兴趣，请随时关注。

## 六、售后规则

1. 因盲盒商品的特殊性，不支持七天无理由退换货。
2. 无限赏内商品属于 IP 定制产品，可能存在轻微蹭色、溢色等涂装瑕疵，此类问题不属于质量问题。平台保证相应产品已获得版权方授权，为正版商品。平台不接受因上述瑕疵提出的退换货申请，请您知悉并谨慎考虑后购买。
3. 如您收到的商品存在损坏、少件或遗失等质量问题，请提供有效凭证，证明签收时商品即存在上述问题。经核实后，平台将提供退换货服务并承担来回运费。
4. **退货申请时限**：自物流签收之日起 7 天内；**换货申请时限**：自物流签收之日起 15 天内。上述时限均按自然日计算。
5. 如需回寄退换货商品，您应在收到卡核一番赏通知之日起 7 天内回寄；春节假期以卡核一番赏公告为准。
6. 品牌方售后处理周期以品牌方时效为准。
