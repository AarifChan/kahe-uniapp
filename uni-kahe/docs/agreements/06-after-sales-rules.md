# 售后与退换货规则

## 一、七天无理由退换货

1. 抽卡机、一番赏、盲盒类商品会在付款后完成结果获取，具有随机性和即时拆封属性，不适用七天无理由退货。
2. 已集赏的好物商品不支持七天无理由退款，包括虚拟商品。
3. 请您在购买前仔细查看商品信息、赏品概率、品相及相关规则，谨慎、理性消费。

## 二、可申请售后的情形

如您收到的商品存在以下问题，可联系在线客服申请售后：

- 商品损坏或运输损坏；
- 商品存在质量问题；
- 错发、漏发、少件或遗失；
- 其他经客服核实符合售后条件的问题。

## 三、售后凭证

1. 请您提供有效凭证，证明商品在签收时即存在上述问题。
2. 建议提供连续、完整的开箱视频，并清晰展示快递面单、外包装、封箱状态、开箱过程及问题商品细节。
3. 客服可能根据问题类型要求您补充商品照片、订单信息、物流信息或其他必要材料。

## 四、非质量问题的常见情形

1. 一番赏、无限赏等 IP 定制商品可能存在轻微蹭色、溢色等涂装问题，此类品牌方出厂瑕疵不属于质量问题。
2. 卡牌商品的正常品相范围以《卡牌品相定义》为准。
3. 对上述不属于质量问题的情形，平台不接受由此提出的退换货申请，请您知悉并谨慎考虑后购买。

## 五、处理方式与运费

1. 经核实符合售后条件的，平台将根据实际情况提供退货、换货或其他解决方案。
2. 因质量问题、错发、漏发等平台责任产生的退换货，来回运费由平台承担。
3. 同款商品可调换的，以实际库存为准；不支持擅自调换为其他款赏品。
4. 品牌方售后商品的处理方式及周期，以品牌方售后政策和实际处理时效为准。

## 六、申请与回寄时限

1. **退货申请**：自物流签收之日起 7 天内提出。
2. **换货申请**：自物流签收之日起 15 天内提出。
3. 上述时限均按自然日计算。
4. 如需回寄退换货商品，您应在收到平台通知之日起 7 天内回寄；春节假期等特殊时期以平台公告为准。

## 七、恶意售后行为

为保障用户公平享有冲赏及售后服务，平台会对恶意行为进行监测。恶意行为包括但不限于：

- 开箱后无质量问题而以各种理由要求退款；
- 欺骗或与他人联合欺骗其他冲赏用户；
- 利用系统漏洞恶意冲赏；
- 伪造、篡改售后凭证或实施其他滥用售后服务的行为。

对于恶意行为，平台有权要求用户退还因此获得的额外利益并进行警告；出现两次恶意行为的，用户可能被列入黑名单并被冻结平台账户，无法继续使用一番赏购买服务及其他相关服务。涉嫌违法的，平台保留依法追究责任的权利。

## 八、联系客服

如需申请售后，请前往“我的”页面点击“联系客服”，提交订单信息及相关凭证。具体处理结果以客服核实为准。
