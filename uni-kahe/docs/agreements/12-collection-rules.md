# 集赏行动购买须知

## 一、玩法概述

用户可以通过“换卡集市”，将已购买且未发货的卡牌商品用于集赏。完成后，用于集赏的商品将替换为想要集赏的商品，并发放至用户寄存柜中，用户可前往寄存柜申请发货。

## 二、如何集赏

1. 购买商品后，用户可前往“首页－换卡集市”，点击进入玩法页面，浏览并选择商品。
2. 选中想要的好物商品后，页面将默认展示可用于集赏的商品。
3. 点击选择已获得的商品，将按照对应商品的助力值积累集赏进度。当进度达到 100% 时，点击“立即集赏”，即可将已选商品集赏为目标商品。
4. 目标商品包括实物商品与虚拟商品。虚拟商品可能附赠无门槛抵扣券、优惠券、包邮券等权益，具体以集赏页面显示为准；所需普通款商品个数以页面展示为准。
5. 集赏完成后，用户可在玩法页面点击“记录”，查看已完成的集赏记录。
6. 当用户选中的商品使集赏进度超过 100% 时，页面将提示已达到集赏所需商品素材，无需继续增选商品。
7. 当集赏进度超过 100%，且减少任一普通款商品后进度将低于 100% 时，用户仍可完成集赏；超出部分不予退回，请合理选择。
8. 可供集赏的好物商品库存有限，兑完即止。部分商品设有集赏次数限制，每个卡核账号每日只能集赏指定次数，次日零点刷新，具体限制以对应玩法页面为准。
9. 禁止使用外挂、脚本、同步器、按键宏、云手机多开、硬件辅助设备或其他第三方辅助工具。若发现违规，平台将采取相应处理措施，包括但不限于暂时禁止参与集赏兑换、取消集赏资格、永久封停账号；情节严重的，平台保留追究用户法律责任的权利。

## 三、发货与售后

1. 完成集赏后无法撤回。现货商品将发放至用户寄存柜，用户可前往“寄存柜－待处理”查看并申请发货。
2. 如集赏所得好物商品为预售类型，“寄存柜－待处理”中将展示预计到货时间，到货后可申请发货。
3. 集赏所得商品支持与其他待发货商品合并发货，包邮门槛与卡核平台包邮政策一致。
4. 已集赏的好物商品不支持七天无理由退款，包括虚拟商品。其余事项按照本须知及《卡核用户服务协议》《发货规则》《售后与退换货规则》执行。
