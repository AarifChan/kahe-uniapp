# 发货规则

## 一、申请发货

1. 开赏、集赏或其他玩法所得商品会放入寄存柜，所有商品均需由您自行申请发货。
2. 您可前往“寄存柜－待处理”查看商品并提交发货申请。
3. 预售商品将在“寄存柜－待处理”中展示预计到货时间，到货后方可申请发货。
4. 支持合并发货的商品，可与其他待发货商品合并提交；具体以发货页面展示为准。

## 二、收货信息与发货范围

1. 请务必填写真实、准确、有效的收货人、联系电话及收货地址，并在提交前仔细核对。
2. 因地址错误、联系方式失效或其他个人原因导致的延误、退回、遗失或其他损失，由您自行承担。
3. 目前仅支持发货至中国大陆区域，香港、澳门、台湾地区及海外地区暂不支持。

## 三、运费与承运

1. 一件即可申请发货，无发货数量门槛。
2. 运费为 12 元/单，由您在申请发货时支付。
3. 承运方以发货页面或订单页面实际展示为准。
4. 如商品或活动另有包邮、运费券等规则，以对应页面公示为准。

## 四、发货时效

1. 平台根据申请发货的先后顺序，在 1～7 个工作日内安排发货。
2. 如遇法定节假日或特殊情况，发货可能暂停或顺延 1～5 天。
3. 预售、缺货、调货或品牌方售后商品的发货时间，以商品页面或客服通知为准。
4. 平台会尽力将现货商品尽快送达，但物流运输时间不属于上述发货时效。

## 五、收货与开箱凭证

1. 收到商品时，请先检查外包装及商品状态。
2. 建议从快递外包装未拆封状态开始，连续、完整地录制开箱视频，清晰展示快递面单、封箱状态、开箱过程及商品细节。
3. 如遇运输损坏、质量问题、错发、漏发、少件或遗失，请及时联系在线客服，并提供开箱视频及其他有效凭证。
4. 具体售后申请条件、时限及处理方式以《售后与退换货规则》为准。

## 六、卡牌品相确认

1. 不同用户对卡牌品相、评级评分可能有不同需求。
2. 申请发货前，请在购买界面查看商品图片、品相标识及《卡牌品相定义》，确认后再提交发货。
3. 因商品版本、品牌方及生产工艺不同，品相判定可能存在轻微差异；如发生争议，可联系客服协助核实。
