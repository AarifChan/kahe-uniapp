# 购买说明

亲爱的顾客，您好！购买前请认真阅读并知悉本说明，确认后再进行购买。

## 一、一番赏相关定义

1. 单个 IP 主题的一番赏构成一个赏池，每个赏池包含若干个赏箱。
2. 赏箱内可能包含“最终赏”以及 SAR、UR、SSR、SR、R 等不同等级的赏品。赏品等级仅为赏品等级的命名方式，赏品均配有图片及介绍。
3. 赏箱页面会实时更新各等级赏品余量，供您参考。
4. 开赏后的赏品会放入寄存柜，您需要填写收货地址并申请发货。

## 二、无限赏相关说明

1. 盲盒商品请谨慎、理性购买，未成年人禁止下单。
2. 您可根据需求点击购买 N 个赏品。商品不存在空盒，100% 有赏品；赏品类型及获得概率以赏品页面显示为准。
3. 所有赏品概率及获得记录均在赏品详情页展示，请参考后下单。平台遵循公平、公正、公开原则。

## 三、赏品获取

1. 开赏得到相应等级的赏品后，赏品将放入寄存柜，等待您申请发货。
2. “最终赏”赠送给最后一个购买商品的用户，以系统记录的操作时间为准。
3. 本平台提倡谨慎判断、理性消费。

## 四、概率与消费提示

1. 抽卡机、一番赏、盲盒类商品的抽取结果具有随机性，不同系列商品的获取概率可能不同。
2. 付款前请仔细查看商品详情页公示的赏品类型、余量、概率及获得记录。
3. 请根据自身实际需求和经济能力理性消费，切勿盲目或过度消费。

## 五、发货与售后

1. 所有商品均需自行申请发货，您可在“寄存柜－待处理”中查看并操作。
2. 请务必确保收货人、联系电话及收货地址真实、准确、有效。
3. 具体承运方、运费、发货范围及时效以《发货规则》《发货须知》和订单页面公示为准。
4. 抽卡机、一番赏、盲盒类商品会在付款后完成结果获取，不适用七天无理由退货。
5. 若存在质量问题、错发、漏发等售后问题，请联系客服并提供商品开箱视频，具体以《售后与退换货规则》为准。

## 六、商品缺货处理

由于市场变化、系统问题、不可抗力等因素影响，您提交订单中的商品可能出现缺货。在此情形下，平台将以有效方式（包括但不限于向您提供的联系电话发送手机短信）通知您并提供解决方案，包括但不限于取消订单、换货、调货等。

请您在未收到商品前留意通知。若平台自发出通知起一周内超过两次无法与您取得电话联系，且您在收到通知超过 30 天后仍未主动联系在线客服，平台有权取消订单并退还您支付的冲赏费用。缺货商品是否补货不再另行通知，如您对该商品感兴趣，请随时关注。

## 七、优惠券与积分

平台提供的无门槛券、积分等，可在兑换商品时按照页面规则用于抵扣。具体可使用的商品和抵扣金额以订单确认页信息为准。

无门槛券、积分等无法转让、兑现或交易。如有人联系您交易积分、无门槛券等，请勿上当受骗；因个人原因造成的损失，由您自行承担。

## 八、联系我们

如果您在使用过程中遇到问题，请在“我的”页面点击“联系客服”，根据提示联系客服咨询。
