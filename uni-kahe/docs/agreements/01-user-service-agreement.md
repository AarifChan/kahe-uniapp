# 卡核用户服务协议

## 提示条款

欢迎您与卡核经营者（详见定义条款）共同签署本《卡核用户服务协议》（下称“本协议”）并使用卡核服务！

各服务条款前所列索引关键词仅为帮助您理解该条款表达的主旨之用，不影响或限制本协议条款的含义或解释。为维护您自身权益，建议您仔细阅读各条款具体表述。

### 审慎阅读

您在申请注册流程中点击同意本协议之前，应当认真阅读本协议。请您务必审慎阅读、充分理解各条款内容，特别是免除或者限制责任的条款、法律适用和争议解决条款。免除或者限制责任的条款将以粗体下划线标识，您应重点阅读。如您对协议有任何疑问，可向卡核客服咨询。

### 签约动作

当您按照注册页面提示填写信息、阅读并同意本协议且完成全部注册程序后，即表示您已充分阅读、理解并接受本协议的全部内容，并与卡核经营者达成一致，成为卡核用户。阅读本协议的过程中，如果您不同意本协议或其中任何条款约定，您应立即停止注册程序。

## 一、定义

1. **卡核**：指卡核微信小程序，名称为“卡核丨手办模玩一番赏”。
2. **卡核经营者**：指经营卡核的各法律主体，目前为佛山市顺德区卡核贸易商行。卡核经营者可能根据卡核的业务调整而发生变更。
3. **卡核服务**：指卡核基于互联网，以包含卡核微信小程序等在内的各种形态（包括未来技术发展出现的新的服务形态）向您提供的各项服务。
4. **卡核规则**：包括卡核各频道内已经发布及后续发布的全部规则、解读、公告等内容，以及卡核经营者在网站、圈子、论坛、个人中心内发布的各类规则、实施细则、产品流程说明、公告等。
5. **关联公司**：指除卡核经营者外的关联法律主体。
6. **同一用户**：使用同一身份认证信息，或经卡核经营者排查认定多个卡核账户的实际控制人为同一人的，均视为同一用户。

## 二、协议范围

### 2.1 签约主体

**平等主体**：本协议由您与卡核经营者共同缔结，对您与卡核经营者均具有合同效力。

**主体信息**：卡核经营者是指经营卡核的各法律主体。本协议项下，卡核经营者可能根据卡核的业务调整而发生变更，变更后的卡核经营者与您共同履行本协议并向您提供服务，经营者的变更不会影响您在本协议项下的权益。卡核经营者还有可能因提供新的卡核服务而新增。如您使用新增的卡核服务，视为您同意新增的经营者与您共同履行本协议。发生争议时，您可根据具体使用的服务及对您权益产生影响的具体行为对象，确定与您履约的主体及争议相对方。

### 2.2 补充协议

由于互联网高速发展，本协议列明的条款并不能完整罗列并覆盖您与卡核的所有权利与义务，现有约定也不能保证完全符合未来发展的需求。因此，卡核未来新增的协议等均为本协议的补充协议，与本协议不可分割且具有同等法律效力。如有新增协议，卡核将对您进行告知；如您继续使用卡核服务，视为您同意上述补充协议。

## 三、账户注册与使用

### 3.1 用户资格

您确认，在您开始注册程序并使用卡核服务前，应当具备中华人民共和国法律规定的与您行为相适应的民事行为能力。若您不具备前述民事行为能力，则您及您的监护人应依照法律规定承担因此导致的一切后果。

此外，您还需确保您不是任何国家、国际组织或者地域实施的贸易限制、制裁或其他法律、规则限制的对象，否则您可能无法正常注册及使用卡核服务。

### 3.2 账户说明

**账户获得**：目前卡核使用微信提供的第三方平台账户登录。您根据登录时的相关提示填写必要信息后，将获得卡核账户。卡核只允许每位用户使用一个卡核账户。如有证据证明或卡核经营者根据各类数据规则判断您存在不当注册或不当使用多个卡核账户的情形，卡核经营者可采取冻结或关闭账户、取消订单、拒绝提供服务等措施；如给卡核及相关方造成损失，您还应承担赔偿责任。

**账户使用**：由于您的卡核账户关联您的个人信息及卡核商业信息，账户仅限您本人使用。未经卡核同意，您直接或间接授权第三方使用您的卡核账户或获取账户项下信息的行为无效。如卡核经营者根据卡核规则中约定的违约认定程序及标准，判断您的账户使用可能危及账户安全或卡核信息安全，卡核经营者可拒绝提供相应服务或终止本协议。

**账户转让**：由于用户账户关联用户信用信息，仅在有法律明文规定、司法裁定或经卡核经营者同意，并符合卡核规则规定的账户转让流程的情况下，您方可进行账户转让。账户一经转让，该账户项下权利义务一并转移。除此以外，账户不得以任何方式转让，否则卡核经营者有权追究您的违约责任，由此产生的一切责任均由您承担。

**实名认证**：为使您更好地使用卡核的各项服务并保障账户安全，卡核有权要求您按照我国法律规定完成实名认证。

## 四、商品购买规则

1. 本平台的一番赏以“一番赏”形式售卖玩具，供用户购买。
2. “一番赏”为计算机软件开赏游戏产品，符合《中华人民共和国消费者权益保护法》第三章第二十五条第（三）项细则的要求；一经开赏即视为已拆封，售出不支持退货。
3. 所有购买行为均应遵守本平台《卡核用户服务协议》，18 周岁以下未成年人禁止购买。
4. 本平台提倡谨慎判断、理性消费，购买者应对自身作出的消费行为负责。

## 五、发货与售后

1. 开赏后的赏品会放进寄存柜，您可以到“寄存柜”内手动申请发货。
2. 请务必确保填写的默认地址真实有效，因地址错误或其他个人原因导致的损失由您自行承担。
3. 平台会根据申请发货的先后顺序安排发货；如遇节假日或特殊情况，发货可能暂停或延迟。
4. 平台默认使用中通物流，1 件即可起发；满 5 件可享受国内包邮，不足 5 件需支付 10 元邮费。
5. 商品不支持七天无理由退换货；如有质量问题，请联系客服处理。具体以《发货规则》《发货须知》及《售后与退换货规则》为准。

## 六、违约责任

用户出现恶意行为的，平台有权要求其退还因恶意行为获得的额外利益并进行警告；出现两次恶意行为的，用户将被列入黑名单并被冻结平台账户。

恶意行为包括但不限于：开箱后无质量问题而以各种理由要求退款、欺骗或与他人联合欺骗其他冲赏用户、利用系统漏洞恶意冲赏等。

## 七、法律适用与争议解决

本协议的订立、生效、解释、修订、补充、终止、执行与争议解决均适用中华人民共和国法律。法律无相关规定的，参照商业惯例或行业惯例。

您因使用卡核服务所产生及与卡核服务有关的争议，由卡核与您协商解决；协商不成时，任何一方均可向被告所在地有管辖权的人民法院提起诉讼。
