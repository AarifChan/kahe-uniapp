# 星曜抽选活动规则

## 一、活动介绍

1. 本活动为回馈顾客活动。每日达到消费门槛后，用户即可领取实体参与券，参与券随购物订单物流一并发出，不另收物流快递费用。
2. 收到参与券后，用户可在活动页面提交参与券上的参与码参与活动。
3. 当参与数量达到活动要求时，平台将从本期已提交的券码中抽取获得者。
4. 参与券仅限参与当期活动，无法留到下期使用。请收到后及时参与，过期未使用视为自愿放弃参与资格。

## 二、参与券介绍

1. 本券可免费参与抽选活动，获得方式请留意官方活动说明。
2. 每期奖品不同，请及时查看本期对应奖品。
3. 每期参与券仅适合当期使用，过期未使用视为放弃参与。
4. 如出现参与码无效，请及时联系客服处理。
5. 参与券及参与码不得伪造、篡改或以其他不正当方式获取、使用；发现异常时，平台有权核实并取消相应参与资格。
